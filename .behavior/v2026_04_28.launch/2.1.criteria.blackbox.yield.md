# blackbox criteria: sdk-config

## usecase.1 = access typed config with secrets

```
given(schema defined, config file with $.at() placeholders, suppliers registered)
  when(getConfig() called)
    then(returns typed config object)
      sothat(developer gets intellisense on config.database.password)
    then($.at() placeholders are filled with actual secrets)
      sothat(secrets come from ssm/secrets manager)
    then(config validates against schema)
      sothat(schema drift is caught)
```

## usecase.2 = access static config sync

```
given(config file exists)
  when(getConfig.static() called)
    then(returns raw config synchronously)
      sothat(no await needed for static-only access)
    then($.at() placeholders are NOT filled)
      sothat(static returns yaml/json5 values as-is)
    then(schema is NOT validated)
      sothat(placeholder strings don't fail validation)
```

## usecase.3 = validation behavior by environment

```
given(config that doesn't match schema)
  when(environment is test/*)
    then(failfast with validation error)
      sothat(schema issues caught early in dev)

  when(environment is prep/*)
    then(failfast with validation error)
      sothat(schema issues caught before prod)

  when(environment is prod/local)
    then(failfast with validation error)
      sothat(local prod test catches issues)

  when(environment is prod/cloud)
    then(warn only, return config anyway)
      sothat(production doesn't crash from schema drift)
```

## usecase.4 = auto-resolution of ssm paths

```
given($.at(aws::param) in config at path database.password)
given(repo name is svc-raisefloor)
given(environment.access is prod)
  when(filled)
    then(resolves to ssm path /svc-raisefloor/prod/database.password)
      sothat(developer doesn't construct paths manually)
```

## usecase.5 = explicit ssm paths

```
given($.at(aws::param/shared/db/password) in config)
  when(filled)
    then(resolves to ssm path /shared/db/password exactly)
      sothat(cross-repo secrets can be accessed)
```

## usecase.6 = failfast on unknown supplier

```
given($.at(unknown::scheme) in config)
given(no supplier registered for unknown:: scheme)
  when(getConfig() called)
    then(failfast with clear error)
      sothat(developer knows to register supplier or fix uri)
    then(error names the unknown scheme)
      sothat(developer knows which placeholder failed)
```

## usecase.7 = supplier retry then failfast

```
given(ssm call fails transiently)
  when(supplier retries internally)
    then(either returns value after retry succeeds)
    then(or failfast after retries exhausted)
      sothat(no stale data, no silent failures)
```

## usecase.8 = cache behavior

```
given(getConfig() called, cache TTL is 5 minutes)
  when(getConfig() called again within 5 minutes)
    then(returns cached value)
      sothat(ssm is not called repeatedly)

  when(getConfig() called after 5 minutes)
    then(fetches fresh value from ssm)
      sothat(rotated secrets are picked up)
```

## usecase.9 = repo name from package.json

```
given(package.json has name "svc-raisefloor")
  when(auto-resolution builds ssm path)
    then(uses "svc-raisefloor" as repo name)
      sothat(no explicit config needed)

given(genGetConfig called with explicit repoName override)
  when(auto-resolution builds ssm path)
    then(uses explicit repoName instead of package.json)
      sothat(override is possible when needed)
```

## usecase.10 = multiple suppliers

```
given(suppliers array has [ssmSupplier, secretsManagerSupplier])
given($.at(aws::param) and $.at(aws::secret) in config)
  when(filled)
    then(each placeholder matched to correct supplier by uri scheme)
      sothat(different secret stores can coexist)
```

## usecase.11 = file selection by environment

```
given(config/test.yml, config/prep.yml, config/prod.yml exist)
given(environment.access is "test")
  when(genGetConfig resolves statics glob)
    then(loads config/test.yml)
      sothat(correct env file is used)

given(environment.access is "prod")
  when(genGetConfig resolves statics glob)
    then(loads config/prod.yml for both prod/local and prod/cloud)
      sothat(file selection is by access, not full path)
```
