# fast follow: SOPS supplier

## .what

add `genSdkConfigSupplierSops` to enable encrypted secrets in git via Mozilla SOPS.

## .why

SOPS enables git-tracked secrets with encryption at rest:
- secrets live in repo, encrypted
- decrypted at runtime
- git-friendly diffs (structure visible, values encrypted)
- no external secret store required for simple setups

## .usage vision

```yaml
# secrets.sops.yml (committed to git, SOPS-encrypted)
database:
  password: ENC[AES256_GCM,data:Tr7o=,iv:1=,tag:k=]
api:
  key: ENC[AES256_GCM,data:CwE4=,iv:2=,tag:j=]
sops:
  age:
    - recipient: age1...
      enc: |
        -----BEGIN AGE ENCRYPTED FILE-----
        ...
```

```yaml
# config/prod.yml (regular config, references SOPS file)
database:
  host: db.prod.example.com
  password: $.at(sops::secrets.sops.yml#database.password)
api:
  key: $.at(sops::secrets.sops.yml#api.key)
  url: https://api.prod.example.com
```

## .design questions

### 1. key source

where do decryption keys come from?

| option | pros | cons |
|--------|------|------|
| age via env var | simple, no infra | key management manual |
| AWS KMS | IAM-based, no key exposure | AWS dependency |
| PGP keys | distributed trust | complex key management |

**recommendation:** support age first (simplest), KMS second (enterprise)

### 2. implementation approach

| approach | pros | cons |
|----------|------|------|
| CLI via child_process | works with all backends | requires sops binary |
| sops-age library | pure JS, no binary | age-only |
| @figedi/sops | KMS support, no binary | limited backends |

**recommendation:** start with `sops-age` library for age backend, add CLI fallback for other backends

### 3. path format

use standard `$.at(sops::file#keypath)` pattern:
- `sops::secrets.sops.yml#database.password` — decrypt file, extract nested key
- supplier caches decrypted file to avoid re-decryption per key

## .implementation sketch

```ts
export const genSdkConfigSupplierSops = (input: {
  age?: { privateKey: string };
  cache?: Map<string, Record<string, unknown>>; // cache decrypted files
}): SdkConfigSupplier => {
  const cache = input.cache ?? new Map();

  return {
    scheme: 'sops',
    supply: async ({ path }) => {
      // path = "secrets.sops.yml#database.password"
      const [file, keyPath] = path.split('#');

      // cache decrypted file to avoid re-decryption per key
      if (!cache.has(file)) {
        cache.set(file, await decryptSopsFile(file, input));
      }

      return getNestedValue(cache.get(file)!, keyPath);
    },
  };
};
```
