# blueprint: sdk-config

## summary

build a typed config library with pluggable credential suppliers:
- `genGetConfig({ schema, statics, cache, suppliers, environment })` returns getConfig function
- `getConfig()` returns typed, filled config (async)
- `getConfig.static()` returns raw config without fill (sync)
- `getConfig.filled()` alias for getConfig() (explicit)
- `$.at(aws::param)` placeholders auto-derive paths from repo + env + key
- `$.at(aws::param/explicit/path)` placeholders use explicit path
- pluggable suppliers match by uri scheme
- zod schema for validation + type inference

## codepath tree

### domain.objects

```
[+] SdkConfigEnvironment
    .what = interface for environment shape
    .shape = { access: 'test' | 'prep' | 'prod'; compute: 'local' | 'cloud' }

[+] SdkConfigSupplier
    .what = interface for credential supplier
    .shape = { scheme: string; supply: (input: { path: string }) => Promise<string> }

[+] SdkConfigUri
    .what = parsed $.at() uri
    .shape = { scheme: string; explicitPath: string | null }
    .unique = ['scheme', 'explicitPath']
```

### domain.operations — transformers

```
[+] asSdkConfigUri
    .what = parse $.at() string to SdkConfigUri
    .input = { raw: string }
    .output = SdkConfigUri
    .examples:
      - '$.at(aws::param)' → { scheme: 'aws::param', explicitPath: null }
      - '$.at(aws::param/shared/db/pass)' → { scheme: 'aws::param', explicitPath: '/shared/db/pass' }
      - '$.at(aws::secret)' → { scheme: 'aws::secret', explicitPath: null }

[+] asSdkConfigPath
    .what = derive full path from uri + context
    .input = { uri: SdkConfigUri; repoName: string; access: string; keyPath: string }
    .output = string
    .examples:
      - { uri: { scheme: 'aws::param', explicitPath: null }, repoName: 'svc-x', access: 'prod', keyPath: 'database.password' }
        → '/svc-x/prod/database.password'
      - { uri: { scheme: 'aws::param', explicitPath: '/shared/db/pass' }, ... }
        → '/shared/db/pass'
```

### domain.operations — communicators

```
[+] asStaticConfig
    .what = load config file for environment
    .input = { statics: string; access: string }
    .output = object
    .behavior:
      - glob matches statics pattern
      - filters to file with access in name (e.g., config/prod.yml for access='prod')
      - parses yaml or json5
      - returns raw object (placeholders not filled)

[+] getRepoName
    .what = read repo name from package.json or use override
    .input = { override?: string }
    .output = string
    .behavior:
      - if override provided, return override
      - else read package.json name field
```

### domain.operations — orchestrators

```
[+] asFilledConfig
    .what = recursively fill $.at() placeholders in config object
    .input = { config: object; suppliers: SdkConfigSupplier[]; repoName: string; access: string }
    .output = object (same shape, placeholders filled)
    .behavior:
      - walks config recursively
      - for each $.at() string, finds supplier by scheme
      - derives path via asSdkConfigPath
      - calls supplier.supply({ path })
      - replaces placeholder with supplied value

[+] genSdkConfigSupplierAwsParameterStore
    .what = factory for SSM parameter store supplier
    .input = { retries?: number }
    .output = SdkConfigSupplier with scheme='aws::param'
    .behavior:
      - creates supplier that calls SSM GetParameter
      - retries on transient failures
      - failfast after retries exhausted

[+] genSdkConfigSupplierAwsSecretsManager
    .what = factory for Secrets Manager supplier
    .input = { retries?: number }
    .output = SdkConfigSupplier with scheme='aws::secret'
    .behavior:
      - creates supplier that calls SecretsManager GetSecretValue
      - retries on transient failures
      - failfast after retries exhausted

[+] genGetConfig
    .what = main factory that returns getConfig function
    .input = {
        schema: ZodSchema;
        statics: string;           # glob pattern
        cache: SimpleCache;
        suppliers: SdkConfigSupplier[];
        environment: SdkConfigEnvironment;
        repoName?: string;         # optional override
      }
    .output = getConfig function with .static() and .filled() methods
    .behavior:
      - getConfig() = getConfig.filled()
        - load static config via asStaticConfig
        - fill placeholders via asFilledConfig
        - validate against schema
          - test/prep/prod-local: failfast on mismatch
          - prod-cloud: warn only, return anyway
        - wrap with cache
        - return typed result
      - getConfig.static()
        - load static config via asStaticConfig (sync)
        - no fill, no validation
        - return raw object
```

## supplier interface

```ts
interface SdkConfigSupplier {
  /** scheme this supplier handles, e.g., 'aws::param' */
  scheme: string;

  /** fetch value for path */
  supply: (input: { path: string }) => Promise<string>;
}
```

---

## uri format

```
$.at({scheme})                     # auto-derive: /{repoName}/{access}/{keyPath}
$.at({scheme}/{explicit/path})     # explicit: /{explicit/path}
```

examples:
- `$.at(aws::param)` at key `database.password` → `/svc-x/prod/database.password`
- `$.at(aws::param/shared/db/pass)` → `/shared/db/pass`
- `$.at(aws::secret)` at key `api.key` → `/svc-x/prod/api.key`
