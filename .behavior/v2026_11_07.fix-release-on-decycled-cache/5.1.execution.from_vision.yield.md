## the break, for the pr body

`genGetConfig`'s `cache` input moves from the uni-time `SimpleSyncCache` (with-simple-cache 0.15.3) to the iso-time `SimpleCacheSync` (0.17.3). a cache whose `expiration` cannot hold an `IsoDuration` no longer typechecks — where its type resolves. `@ehmpathy/simple-dynamodb-cache@1.0.8` is accepted by tsc (its `SimpleAsyncCache` import no longer resolves → `any`) but fails silent at runtime — async caches never worked with the sync wrapper (pre-extant, F7). `simple-in-memory-cache@0.4.0` is refused only where its `@ehmpathy/uni-time` resolves `UniDuration` (<= 1.9.x); on uni-time 1.10.0 the type collapses to `any` and tsc accepts it. no runtime break: sdk-config passes no expiration. recommended: `simple-in-memory-cache` >= 0.4.2. bump: minor, 0.3.0 → 0.4.0, via a `feat(cache):` header (F1).
