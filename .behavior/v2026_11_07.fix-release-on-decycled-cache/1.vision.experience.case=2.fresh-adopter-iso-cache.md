# c2 — fresh adopter wires an iso-time cache (happy × criti)

## narrative

a new service copies the readme: `createCache({ expiration: { minutes: 5 } })` from `simple-in-memory-cache`. pnpm installs 0.5.1; a service pinned at 0.4.2 sees the same — both type `expiration` as `IsoDuration`. tsc is clean. the first `getConfig()` calls the suppliers. the second returns from the cache, with no supplier call. the service had no dpdm exclusion, so it has none to drop.

## timeline

```
given a service with no prior cache, on simple-in-memory-cache 0.4.2 or 0.5.1
when [t0] it passes createCache({ expiration: { minutes: 5 } }) to genGetConfig and calls getConfig()
then tsc is clean
  and the suppliers fill the config
when [t1] it calls getConfig() again
then the config returns from the cache
  and no supplier is called
```

grounding: `genGetConfig.integration.test.ts` `[case8]` — `[t0]` 0.5.1 fill, `[t1]` 0.4.2 fill, `[t3]` 0.5.1 warm hit with no supplier call.
