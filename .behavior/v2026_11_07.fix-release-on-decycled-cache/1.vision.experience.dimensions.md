# experience dimensions — sdk-config on the iso-time cache contract

two actors, each with its own space. `actor` is the root axis: no adopter value implies a maintainer value, and vice versa.

| axis | values | why orthogonal |
|---|---|---|
| **actor** | `adopter` (a service that wires `genGetConfig`, e.g. `ahbode/svc-home-services`) · `maintainer` (ships sdk-config) | who walks the path; each value opens its own sub-space below |

the boundaries a walk crosses (lockfile · type system · runtime · dpdm · commit header · release action) are a **column of the catalog**, not an axis: a boundary is where a cell's walk goes, not a value an actor picks.

## adopter space — A × B × S × K

| axis | values | why orthogonal |
|---|---|---|
| A. cache glossary | `iso` (`simple-in-memory-cache` 0.4.2 / 0.5.1) · `uni-mem` (`simple-in-memory-cache` 0.4.0) · `uni-ddb` (`@ehmpathy/simple-dynamodb-cache` 1.0.8) · `uni-shape` (hand-rolled, `expiration` takes only `{ minutes }` — the hermetic stand-in for `uni-mem`'s shape where `UniDuration` resolves) · `none` (hand-rolled, no expiration option) | what the adopter passes |
| B. adopter graph | `workaround` (dpdm exclusion `with-simple-cache@0.15.3` and/or an override) · `bare` | what the lockfile holds; any A pairs with any B |
| S. cache state at call | `cold` · `warm` · `expired` | a runtime fact; any A × B can meet any state |
| K. call concurrency | `single` · `concurrent` | how many fills race; independent of state |

### the walk

B touches only the lockfile and dpdm, never runtime or tsc. so every A × S × K cell reads the same under `workaround` and `bare` — B adds one column (the dpdm moment), walked first.

**A × B** (typecheck + dpdm)

| A \ B | workaround | bare |
|---|---|---|
| iso | demoed c1 (densest: drop exclusion + pin; tsc clean; dpdm clean) | demoed c2 (tsc clean; dpdm has no exclusion to drop) |
| uni-mem | demoed c3 (tsc refuses where `UniDuration` resolves; else accepted) | demoed c3 (same — B does not change the contract) |
| uni-ddb | demoed c4 (tsc accepts — its type collapses to `any`) | demoed c4 (same) |
| uni-shape | clamped — `[case8] [t2]`: tsc refuses (`@ts-expect-error` ×2); the fill still runs past the gate. maps to c3 | clamped (same — B does not change the contract) |
| none | itemized — fits both contracts (case7 Map cache) | itemized (same) |

**A × S × K** (runtime; identical across B)

| A \ S×K | cold·single | warm·single | expired·single | cold·concurrent | warm·concurrent | expired·concurrent |
|---|---|---|---|---|---|---|
| iso | demoed c2 [t0] | demoed c2 [t1] (`[case8] [t3]`; acceptance `[case16] [t1]` on 0.4.2, real aws) | clamped — `[case8] [t5]` refill after a 1s ttl | clamped — `[case8] [t4]` three concurrent calls, one fill | itemized — hit | itemized — one refill (the [t4] + [t5] mechanisms combined) |
| uni-mem | refused graph: impossible (nature) — the build fails first. accepted graph (uni-time 1.10.0, `any`): itemized — fills like iso; sdk-config passes no expiration (the `uni-shape` row clamps that runtime fact) | same split | same split, the cache's own ttl | same split | same split | same split |

| uni-shape | clamped — `[case8] [t2]` fill | itemized — hit, as `none` | impossible (nature) — sdk-config passes no expiration, so the stub never expires | itemized — one fill | itemized — hit | impossible (nature) |

evidence for the iso runtime cells: `[case8] [t3]`–`[t5]` (each also asserts the returned config equals the fill) and acceptance `[case16]`; first seen in a `tsx` probe of `with-simple-cache@0.17.3` `withSimpleCache` over `simple-in-memory-cache@0.5.1` (`expiration: { seconds: 1 }`): 3 concurrent cold calls → 1 fill; a warm call → 0 fills; a call after 1.1s → 1 refill. the cache owns its ttl; sdk-config passes none.

## maintainer space — H × P

| axis | values | why orthogonal |
|---|---|---|
| H. merge header | `feat(cache):` · `break(cache):` · `feat(cache)!:` | the maintainer's pick for the squash header |
| P. approval | `pre-approval` · `post-approval` | the commander's review state; any header can meet either |

| H \ P | pre-approval | post-approval |
|---|---|---|
| feat(cache): | forbidden (nurture) — demoed c6 | demoed c5 → 0.4.0 |
| break(cache): | forbidden (nurture) — demoed c6 | itemized → 1.0.0 (F1, the wisher's call) |
| feat(cache)!: | forbidden (nurture) — demoed c6 | forbidden (nurture) — demoed c5 [t1]: commitlint refuses |

## forbidden / impossible — why, and which

- **nurture** (the behavior rejects it):
  - a uni-time sync cache at the `cache:` input — tsc refuses where its `UniDuration` resolves (c3); where it collapses to `any`, nurture holds at runtime instead: sdk-config passes no expiration.
  - an async cache — NOT barred by any gate (c4); the readme warns. a known hole, pre-extant, F7.
  - a `feat!:` header — commitlint `subject-exclamation-mark: never` refuses it in `test:commits` (c5 [t1]).
  - a release before approval — the driver stops at the pr; only `git.release --apply`, under a human-held quota, enables automerge (c6).
  - a with-simple-cache cycle via sdk-config — the change moves sdk-config's prod graph to 0.17.3 alone (`pnpm why --prod`); dpdm over 0.17.3 reports none. demoed as c1 [t1].
- **nature** (no attempt is possible):
  - any runtime cell for a uni-time cache in a refused graph — the build fails before a call exists.
  - an `expired` cell for a cache with no expiration option.
