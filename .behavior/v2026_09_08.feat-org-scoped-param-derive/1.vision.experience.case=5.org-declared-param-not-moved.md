# case=5 — the org is declared, the param is not yet at the derived path

> cells: `r6` (runtime · config-field · bare · absent) · `o1` (oncall)
> feel = **sharp** · care = **critipath** — densest boundary: this is what the wild looks like today

🔴 **the wisher's F6 verdict promotes this case.** the derived shape is the **target convention**,
and the params in the wild migrate to it — so this is not an edge a few unlucky repos hit. it is
the **transition state every repo passes through** on adoption, between the config edit and the
param move. ⇒ its error message is not a diagnostic for a rare miss; it is the **migration's
primary instrument**, and the derived path it prints is the instruction for what to do next. that
is why this case's whole weight sits on the error text.

## narrative — the oncall at 3am

the `persist-with-rds` template ships the bare form. a service adopts it, declares
`"organization": "ahbode"`, deploys — and the cicd job throws at boot.

why: **the org segment alone does not make a bare placeholder point at where params live today.**
the wild shapes, verified across `ahbode/*`:

| what exists in the store today | shape |
|---|---|
| `/ahbode/svc-notifications/database/role/cicd/for-plan/password` | org · repo · slash-keyPath — **no choice segment** |
| `/ahbode.svc-notifications.dev.database.role.crud.password` | a single dot-delimited name — legacy |

what this wish derives:

```
/ahbode/svc-notifications/prep/database.role.cicd.for-plan.password
```

three shapes, three destinations. the derive shape is the **target convention**, and the param
move to it is deliberately out of this wish's scope. so until a param is moved, a bare
placeholder misses — and the whole value of the change rests on a legible miss.

so it is. the supplier raises `SupplyAbsentError`, which holds the exact path it asked for, and
`genGetConfig` re-raises it as a blocker that names the key, the reason, and the cause:

```
BadRequestError: config requires values that could not be read
  blockers: [{ key: { path: 'database.role.cicd.for-plan.password' }, reason: 'absent',
               cause: SupplyAbsentError: parameter not found
                        path: /ahbode/svc-notifications/prep/database.role.cicd.for-plan.password }]
```

oncall reads one line and knows the move: **put the value at that path, or write the explicit
path back.** no aws console spelunk to guess what was asked for.

## `[tn]` sketch

```ts
given('[case5] organization declared, bare uri, no param at the derived path', () => {
  when('[t0] getConfig() is called and the required field cannot be read', () => {
    then('it throws, and the error names the ORG-SCOPED path it asked for', async () => {
      const error = await getError(async () => getConfig());
      expect(String(error)).toContain(
        '/ahbode/svc-notifications/prep/database.role.cicd.for-plan.password',
      );
    });

    then('the blocker names the config key and the reason', async () => {
      const error = await getError(async () => getConfig());
      expect(String(error)).toContain('database.role.cicd.for-plan.password');
      expect(String(error)).toContain('absent');
    });
  });

  when('[t1] the same field is marked .optional() in the schema', () => {
    // the SCHEMA changes, so the factory is rebuilt. the store is still empty —
    // only the tolerance moved, never the path.
    const getTolerantConfig = genGetConfig({ ...input, schema: SCHEMA_WITH_OPTIONAL_PASSWORD });

    then('the miss is tolerated — the org moves the path, never the tolerance rules', async () => {
      const config = await getTolerantConfig();
      expect(config.database.role.cicd['for-plan'].password).toBeUndefined();
      expect(supplied.paths).toContain(                  // the SAME derived path was still asked for
        '/ahbode/svc-notifications/prep/database.role.cicd.for-plan.password',
      );
    });
  });

  when('[t2] the param is then put at the derived path', () => {
    then('the next boot fills it with no config edit', async () => {
      // the STORE changes, not the config — that is the whole claim
      await store.set(
        '/ahbode/svc-notifications/prep/database.role.cicd.for-plan.password',
        PARAM_VALUE,
      );
      const config = await getConfig();   // the original factory, original schema, original config
      expect(config.database.role.cicd['for-plan'].password).toEqual(PARAM_VALUE);
    });
  });
});
```

## how it fails safe

| obligation | how |
|---|---|
| **fast** | absence is definitive — the supplier does not retry it (`genSdkConfigSupplierAwsParameterStore.ts:53-60`) |
| **loud** | the derived path appears verbatim in the error's `cause` |
| **teaches the fix** | path + key + `reason: 'absent'` ⇒ move the param there, or write the explicit path |

## what this case pins

- the org segment changes **which** path is asked for; it changes no tolerance rule — a
  `.optional()` field still tolerates the miss (`[t1]`)
- the error must carry the **org-scoped** path, never the pre-change one
