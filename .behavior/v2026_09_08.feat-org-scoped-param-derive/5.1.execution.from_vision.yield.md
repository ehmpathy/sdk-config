## ✅ Q5, answered — the one research item the vision owed

| the limit | aws states | a 4-segment path |
|---|---|---|
| hierarchy depth | **15 levels** max | 4 — **26% of the budget** |
| name length | **1011 chars** you specify (of 2048; 1037 reserved) | ~60 chars |
| charset | `a-zA-Z0-9_.-` plus `/` as the delimiter | conformant, for a slug org |

⇒ **assumption 2 is verified.** a 4-segment path is far inside both limits, and the depth budget
leaves room for 11 more levels — so a future fifth segment is not gated by aws.

which is outside `a-zA-Z0-9_.-`, so aws refuses the name. that is the loud failure F7 accepted, and
`getOneOrg.test.ts` `[case6]` pins the pass-through so a later author does not add the gate by accident
while `repoName` stays ungated.
