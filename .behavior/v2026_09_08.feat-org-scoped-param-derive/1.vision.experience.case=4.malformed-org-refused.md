# case=4 — a non-literal `organization` is refused, loudly, before any store read

> cells: `r13`, `r14` (runtime · malformed · bare · either param state) · `a7` (author, forbidden) · `o2` (oncall)
> feel = **sharp** · care = **critipath** — this is the rejection invariant

> 🔴 **`[t3]` is RE-SUBJECTED, never deleted** (F11). it demoed a malformed **override** —
> `genGetConfig({ org: '   ' })` — and there is no `org` argument, so that *input* is unreachable.
> the step survives on the one source that remains: a **blank declared** `organization`.
>
> ⇒ **what IS deleted is the demand `[t3]` carried**: the refusal named *which* source supplied the
> bad value only because two could. one source means every error names the `organization` field
> outright, and the `org`-inside-`organization` trap F4 recorded costs zero.
>
> ⚠️ **so a blank org is still refused** — `'   '` trims to empty and throws (`getOneOrg`
> `[case3]`). the step, its feel, and its care are unchanged; only its *source* moved.

## narrative — the author who put a secret in the org field

devon wants the org itself to come from the parameter store, so he writes:

```json
{ "organization": "$.at(aws::param/ahbode/org/name)",
  "database": { "password": "$.at(aws::param)" } }
```

the org is read from the **static** config — before any placeholder is filled. so the literal
string `$.at(aws::param/ahbode/org/name)` is what the derive would splice in, and the path would
read:

```
/$.at(aws::param|ahbode|org|name)/svc-x/prep/database.password     ← nonsense
```

that path belongs to no one. if it happened to miss, devon would chase a param that was never
meant to exist; if some other value happened to sit at the no-org path, he would read the
**wrong secret** and never know.

so the behavior refuses. `getConfig()` throws at derive time — before the store is read at all —
and the message names the offending value and the way out:

```
BadRequestError: org cannot be a placeholder
  source: the `organization` field declared in the config
  declared: "$.at(aws::param/ahbode/org/name)"
  hint: the `organization` field declared in the config must hold a literal value,
        never a $.at() placeholder. the org is read before any supplier runs — it is
        what decides the path a supplier reads — so it cannot itself be supplied.
        declare the literal
```

the same refusal fires for `organization: { name: 'ahbode' }`, for `organization: 42`, for
`organization: ""`, and for `organization: "   "` — one rule: **a literal, non-empty string.**
🔴 the *"or no org at all"* half is gone (F8).

### 🔴 one source, so the error names it outright

every refusal carries `source: the `organization` field declared in the config` — the same phrase,
in every throw, because there is exactly one place an org can come from (F11).

⇒ **what that removes is a demand, not a detail.** while a second source existed, the refusal had
to name **which** one supplied the bad value, so a caller was not sent to edit a config field they
never wrote — and since `org` sits inside `organization`, neither the message nor a `toContain`
assertion could do it with the bare word. ⇒ **that constraint had no root of its own.** it was a
property of the second source, and it vanished with it.

## `[tn]` sketch

```ts
given('[case4] a config whose organization is not a literal string', () => {
  when('[t0] organization is a $.at() placeholder + a bare uri is derived, param absent', () => {
    then('getConfig() throws BadRequestError before the supplier is called', async () => {
      const error = await getError(async () => getConfig());
      expect(error).toBeInstanceOf(BadRequestError);
      expect(error.message).toContain('org cannot be a placeholder');
      expect(supplied.paths).toEqual([]);      // ← refused before any store read
    });

    then('the error names the field and the offending value', async () => {
      const error = await getError(async () => getConfig());
      expect(String(error)).toContain('`organization` field');
      expect(String(error)).toContain('$.at(aws::param/ahbode/org/name)');
      // 🔴 the F11 clamp: one source, so one remedy. this goes red the moment a
      // call-site lever is re-introduced and the hint grows a second fix.
      expect(error.message).not.toContain('genGetConfig');
    });
  });

  when('[t1] the same config, but a value DOES sit at the no-org path', () => {
    // the STORE changes, not the config — a real value is placed where a quiet
    // fallback would land, so the refusal has something to wrongly hand back
    beforeAll(async () => {
      await store.set('/svc-x/prep/database.password', SOMEONE_ELSES_SECRET);
    });

    then('it still throws — it never quietly hands back the wrong secret', async () => {
      const error = await getError(async () => getConfig());
      expect(error).toBeInstanceOf(BadRequestError);
    });

    then('and the store was never read at all', async () => {
      await getError(async () => getConfig());
      expect(supplied.paths).toEqual([]);   // ← this is what makes [t1] ≠ [t0]
    });
  });

  when('[t2] organization is an object, and every uri is EXPLICIT', () => {
    // a DIFFERENT config from the given: object org + no bare uri anywhere.
    // 🔴 this step INVERTED on F8. it once asserted `no throw — the malformed
    // value is never read`. under a REQUIRED org the value is read whether or
    // not a derive needs it, so the refusal fires here too.
    const getExplicitOnlyConfig = genGetConfig({ ...input, statics: STATICS_OBJECT_ORG_EXPLICIT_URIS });

    then('it throws — a required org is validated even where no path needs it', async () => {
      const error = await getError(async () => getExplicitOnlyConfig());
      expect(error).toBeInstanceOf(BadRequestError);
    });

    then('the explicit paths were still never read', async () => {
      await getError(async () => getExplicitOnlyConfig());
      expect(supplied.paths).toEqual([]);
      // ⚠️ this is the COST of F8's `always`, made visible: a repo whose every
      // path is hand-written, and which therefore never consumes an org, is
      // still held to the requirement. it is the one step that would go green
      // again under a LAZY read (see F8's open sub-question).
    });
  });

  when('[t3] the config declares a BLANK organization', () => {
    // 🔴 re-subjected on F11. it was `genGetConfig({ org: '   ' })` — a blank
    // OVERRIDE — and there is no such argument. the blank value is still
    // refused; only its second source is gone.
    const getBlankOrgConfig = genGetConfig({ ...input, statics: STATICS_BLANK_ORG });

    then('it throws — a blank trims to empty, which no path can carry', async () => {
      const error = await getError(async () => getBlankOrgConfig());
      expect(error).toBeInstanceOf(BadRequestError);
      expect(error.message).toContain('org is empty');
    });

    then('the error names the config field, as every refusal here does', async () => {
      const error = await getError(async () => getBlankOrgConfig());
      expect(String(error)).toContain('`organization` field');
      // ⚠️ a bare toContain('org') would hold on any message here, because 'org'
      // sits inside 'organization'. assert the distinguishing phrase instead.
      // 🟡 under two sources this assertion was LOAD-BEARING — it was the only
      //    thing that kept a caller from being sent to edit a file they never
      //    wrote. one source makes it a sanity check, and that drop in weight
      //    is the cost F11 removed.
    });
  });
});
```

## how it fails safe

| obligation | how |
|---|---|
| **fast** | throws at derive, before the first aws call — no retries, no latency |
| **loud** | `BadRequestError` with the offending value and the `source` that declared it |
| **teaches the fix** | 🔴 names the **one** remedy: declare a literal `organization` in the config (F11) |

## the third inert region this case exposes — widened by F8

`malformed` makes **both the uri-form and the param-state axes inert** — the refusal precedes the
derive *and* the store read, so all four `C × D` combos are one experience (`[t0]`, `[t1]`, and now
`[t2]` all assert the same throw). that is deliberate: the alternative (a quiet fallback to the
no-org path) would hand back a wrong-but-present value, which is the failhide this refusal bars.

🔴 **`[t2]` used to be the counterexample that bounded this region**, and F8 absorbed it. once the
org is required rather than read-on-demand, the `explicit` escape disappears — so `malformed` joins
`absent` in a single invalid half where no other axis varies at all (`dimensions.md`, region 3).

## the tradeoff on record

a repo that today carries a non-string `organization` **and** uses a bare placeholder would newly
throw. measured blast radius: **zero** — no repo in `ahbode/*` or `ehmpathy/*` uses the bare form
at all (see `1.vision.yield.md` groundwork). carried as fulcrum **F2**, whose alternative is a
silent fallback to the no-org path.
