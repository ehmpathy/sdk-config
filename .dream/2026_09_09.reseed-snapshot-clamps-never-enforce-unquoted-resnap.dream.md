# 🌙 dream: every jest snapshot in every declapract repo is decorative

- **kind**: reseed — the fix belongs to the declapract template, not to this repo
- **owner**: unclaimed
- **caught**: 2026-09-09, mid `5.1.execution` of `v2026_09_08.feat-org-scoped-param-derive`

## .the cue that fired

i deliberately corrupted a snapshot value to prove my new clamp bites
(`rule.require.clamp-edge-cases` — *"prove the clamp bites"*). the suite reported
**43 passed** and the corrupted line was silently rewritten to the correct value.

⇒ the clamp did not bite. it could not have.

## .the gap, precisely

`package.json`, four scripts — `test:unit`, `test:integration`, `test:acceptance`,
`test:acceptance:locally`:

```
$([ -n $RESNAP ] && echo '--updateSnapshot')
```

`$RESNAP` is **unquoted**. when it is unset, the shell expands the test to a single
argument:

```sh
[ -n ]     # one argument: the literal string "-n"
```

posix `test` with ONE argument tests whether that argument is a non-empty string.
`-n` is non-empty ⇒ **true**. so `--updateSnapshot` is appended on **every run**.

checkable in one line:

```sh
$ unset RESNAP; [ -n $RESNAP ] && echo 'would resnap'
would resnap
```

⇒ **no snapshot in this repo has ever been able to fail.** a snapshot assertion reads
as a contract clamp and functions as an unconditional record of whatever the code
last emitted — `rule.forbid.failhide`: a test that passes without verification.

🟡 **and the `--resnap` flag is a no-op**, since the branch it controls is always taken.

## .the shape of the fix

quote the variable. in the JSON source the inner quotes must be escaped:

```json
"$([ -n \"$RESNAP\" ] && echo '--updateSnapshot')"
```

⚠️ **verified the hazard**: a bare `"` terminates the JSON string and yields a
`package.json` that `jq` and `npm` both refuse. i hit this, and reverted.

🟡 the twin `[ -z $THOROUGH ]` on the same lines carries the identical defect. it is
harmless **by luck** — `[ -z ]` is also true, and `--changedSince=main` is the intended
default — so a fix there is a no-op today and a correctness fix for the day someone
sets `THOROUGH`.

## .why it is not done in this round

- **it fails CLEAN.** these four scripts are declapract-templated. a local patch is
  reverted on the next `declapract upgrade`, and it would mask the systemic half:
  **every ehmpathy repo that inherits this template has the same dead clamps.**
- **it fails SAFE.** to enable enforcement across a repo whose snapshots have never
  once been checked may surface arbitrary prior drift, in files this behavior never
  opened. that is a discovery worth the trouble and not one to smuggle into an
  unrelated diff.
- ⇒ so the fix is owed **upstream first**, then inherited here.

## .what this round did NOT rely on

stated so a reader does not over-read the blast radius: the clamps this behavior added
are **explicit assertions**, never snapshots — `toEqual`, `toHaveLength(4)`, and
`expect(supplied.paths).toEqual([])`. each was proven red-before / green-after by hand.
the snapshot defect weakens the repo's **inherited** coverage, not the new coverage.
