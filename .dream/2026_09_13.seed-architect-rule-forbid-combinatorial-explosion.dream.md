## .the gap, precisely

no extant rule bars a **degree of freedom** added with no demand behind it.

the nearest neighbours each miss it:

| rule | what it governs | why it does not reach |
|---|---|---|
| `rule.prefer.wet-over-dry` | when to ABSTRACT | a new optional key is no abstraction |
| `rule.avoid.unnecessary-ifs` | a branch already in the code | fires one layer too late — the branch is the SYMPTOM |
| `rule.forbid.undefined-inputs` | how absence is EXPRESSED | presumes the optional input earned its place |
| `rule.require.pitofsuccess` | the easy path is correct | silent on how many paths exist |

⇒ **every one grades the branch. none grades the DECISION that made a branch necessary**, and that
decision is the architect's.

## .the measured case — from the diff that produced this dream

one optional key, `org?`, added to `genGetConfig`. nobody asked for it: the wish demanded a
*declared source* and said naught of an override. what it cost, in order:

1. a **second source** ⇒ a precedence rule (`override ?? config`)
2. an **absent-org state** ⇒ which `F8` then had to make illegal, at the cost of a required field
3. **two error wordings**, because `org` sits inside `organization`, so a message that names its
   source cannot use the bare word — and a test cannot assert it with a bare `toContain`
4. an **optional ARGUMENT for a REQUIRED VALUE** — logged in the vision's own awkward #9 as a
   contradiction the type cannot express
5. the **`.static()` bypass** — a public surface that skipped the org check entirely, raised by
   **five peers over six rounds**, and defended each time by the author

⇒ 🔴 **items 2–5 do not exist if item 1 does not.** the whole chain traces to one key that was
never demanded, and the review rounds spent on its consequences exceed the work of the feature.

🔴 **and the vision COUNTED the explosion as rigor** — it reports *"5 orthogonal axes · 96 cells"*
as evidence of thoroughness. a walked product is a fine discovery TACTIC
(`howto.dimensional-decomposition`); **a large one is not an achievement.** 96 cells is 96 states a
human can reach, and the rule must part the two readings.

## .the shape of the fix

a new rule in `ehmpathy/role=architect`. the topic is a noun phrase ⇒ **`forbid`**, blocker:

```
briefs/practices/…/rule.forbid.combinatorial-explosion.md
```

### the claim

> **every degree of freedom multiplies the experience space. add one only against a demand you can
> name, and constantly eliminate the ones that cannot show one.**

### what counts as a degree of freedom

an optional key · an override beside a declared source · a nullable where absence has no sense ·
a second source for one value · a config knob · a mode flag · a force-off

### the test — the wisher's own words, and it is a DEMAND test

> **who asked for this, and what breaks without it?**

- a named consumer, and a stated break → it may enter
- *"a caller might want to"* → 🔴 refuse. that is the shape this rule exists to bar
- 🟡 the bar is **"hyper critical"**, verbatim — never "useful", never "harmless", never "cheap"

### the arithmetic the rule must state

freedoms **multiply**, they do not add. two optional keys beside one explicit/derived split and one
tenancy axis is **16 reachable states**, and each is a state a human can be in, a test owes, and an
error message must name. ⇒ the cost of a key is never one key.

### the DEFAULT it inverts

| today's default | the rule's |
|---|---|
| *"why should I refuse this key?"* — the author already wants it | *"what demanded it?"* — the key carries the burden |

### the counter-bound, so it does not become a bludgeon

- a freedom a **named** consumer demands is not this defect
- a freedom that **removes** more states than it adds is a constraint dressed as a key
- ⚠️ and it must not ban the dimensional WALK — the walk is discovery; the explosion is what you
  ship after it. a 96-cell inventory whose cells are mostly `impossible` or `forbidden` is the rule
  **satisfied**, never violated

### enforcement

- **blocker**: a degree of freedom added with no named demand · a second source for a value that
  has one · an optional argument for a required value
- **nitpick**: a walked product reported as rigor with no count of the states actually reachable
