# 🌙 dream: rhachet practice fix writes raw `@declapract{check.minVersion(...)}` into package.json

kind: reseed · owner: ehmpathy/declapract-typescript-ehmpathy (or declapract) · caught 2026-11-07

## .the cue that fired
`npx declapract apply --practice rhachet` (declapract 0.13.27, declapract-typescript-ehmpathy 0.50.0) on sdk-config added three devDependencies whose value was the literal template string, e.g. `"rhachet-roles-ghlitch": "@declapract{check.minVersion('0.3.0')}"`.

## .the gap, precisely
for a key absent from the target package.json, the fix copies the declared template value verbatim instead of a resolved version. `pnpm install` would then fail on an invalid spec.

## .the shape of the fix
in the package.json fix, map an absent key's `@declapract{check.minVersion('X')}` to `X` (or the latest that satisfies it) before write. clamp with a fixture repo that lacks the key.

also: declapract-typescript-ehmpathy 0.50.0 peer-requires declapract >=0.13.26, but a repo pinned at 0.13.14 got no warn — it crashed on `checks: []` (environments-aws). a version gate with a named fix would help.
