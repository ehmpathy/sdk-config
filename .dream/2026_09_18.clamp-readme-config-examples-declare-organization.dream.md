# 🌙 dream: clamp every readme config example to declare `organization`

- kind = `clamp`
- owner = `ehmpathy/sdk-config`
- caught = 2026-09-18

## .the cue that fired

self review `5.3.verification / r7.has-ergonomics-validated` found **two** readme yaml blocks that
declared no `organization` — a field `F8` made **required** on this very branch. both examples
throw on the first `getConfig()` when copied as written:

- `readme.md:21` — the **quickstart**, the first code block in the file
- `readme.md:160` — the **explicit path example**, whose reader is exactly the all-explicit repo
  the requirement charges for a value they never read

both were fixed in that gate. **the fix is a repair; this dream is the clamp.**

## .the gap, precisely

a readme is an **i/o surface with no test to redden it**. every other input surface in this repo has
a clamp:

| surface | clamped by |
|---|---|
| the derived path | `asSdkConfigPath.test.ts` |
| the required field | `getOneOrg.test.ts` · `genGetConfig.integration.test.ts [case28]` |
| the public export list | `sdk.acceptance.test.ts` |
| **a readme config example** | 🔴 **none at all** |

⇒ so the defect was reachable by every gate on this route — 7 self-reviews, 6 test suites, types,
lint, format — and caught by a human read alone. checkable evidence: `git log -p readme.md` on this
branch shows the field added in the verification stone, long after the requirement shipped in
execution.

## .the shape of the fix

one unit test, no new dependency:

```ts
// readme.test.ts
given('[case1] every yaml config example in the readme', () => {
  const blocks = getAllYamlBlocksFromMarkdown({ path: 'readme.md' });
  when('[t0] each is read as a config a human would copy', () => {
    then('every one declares a top-level `organization`', () => {
      // ⛔ exempt a block that is deliberately a FRAGMENT — mark it ```yaml.fragment
      const offenders = blocks.filter((b) => !b.raw.includes('organization:'));
      expect(offenders).toEqual([]);
    });
  });
});
```

two calls it needs before it lands:

1. **the fragment exemption** — some blocks show one key, not a whole config. an opt-out marker
   (a fenced-info suffix, or a `# fragment` first line) keeps the clamp from a false red
2. **the scope** — readme only, or every `*.md` in the repo? readme is the high-traffic one; a
   wider sweep buys little and reddens on docs that quote errors verbatim

## .why it is not done in this round

the SAFE/CLEAN test (`rule.always.fix-forward-under-scouts-honor`):

- **safe?** ✅ a doc test touches no runtime path
- **clean?** 🔴 **no.** it needs a new test file, a markdown-fence parser, and a fragment-exemption
  convention that does not exist yet — three decisions, none of which this behavior's wish scopes

⇒ `rule.always.scope-onetime-lessons-to-the-behavior` binds: the wish is an org-scoped param derive,
and a readme-lint convention is a repo-wide practice decision. the two **fixes** ride along under
scouts honor; the **clamp** is its own change.

🟡 it earns a **fulcrum** too, since the deferral was a judgment about ripple rather than about size
(the CLEAN half, not the SAFE half).
